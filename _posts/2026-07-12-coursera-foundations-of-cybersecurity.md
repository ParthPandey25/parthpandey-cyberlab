## Key Concepts

### Module 1: Welcome to the Exciting World of Cybersecurity

**Learning Objectives:**
- Define cybersecurity and its importance
- Understand the responsibilities of entry-level cybersecurity analysts
- Recognize how security attacks impact business operations

**My Notes:**

> **Cybersecurity** (or security) is the practice of ensuring confidentiality, integrity, and availability of information by protecting networks, devices, people, and data from unauthorized access or criminal exploitation.

- A **security analyst** is responsible for monitoring and protecting information and systems
- The field has grown dramatically due to increasing digital transformation and threat landscape
- Key responsibilities include: protecting computer and network systems, installing prevention software, conducting periodic security audits

### Module 2: The Evolution of Cybersecurity

**Learning Objectives:**
- Identify the most common types of cyber attacks
- Understand how past attacks have shaped modern security practices
- Recognize the eight CISSP security domains

**My Notes:**

**Historical Attacks That Shaped Cybersecurity:**

| Attack | Year | Significance |
|---|---|---|
| **Brain Virus** | 1986 | First computer virus; spread via floppy disks |
| **Morris Worm** | 1988 | First major internet worm; led to creation of CERTs |
| **Love Letter (ILOVEYOU)** | 2000 | Social engineering via email; demonstrated human vulnerability |
| **Equifax Breach** | 2017 | 143M records exposed; highlighted patch management importance |

**Eight CISSP Security Domains:**

1. **Security and Risk Management** — Goals, risk mitigation, compliance, business continuity
2. **Asset Security** — Securing digital and physical assets
3. **Security Architecture and Engineering** — Optimized data security with effective tools
4. **Communication and Network Security** — Managing and securing physical networks and wireless communications
5. **Identity and Access Management (IAM)** — Keeping data secure by managing and controlling physical/logical assets
6. **Security Assessment and Testing** — Conducting security control testing and audits
7. **Security Operations** — Conducting investigations and implementing preventative measures
8. **Software Development Security** — Using secure coding practices

### Module 3: Protect Against Threats, Risks, and Vulnerabilities

**Learning Objectives:**
- Define security frameworks and controls
- Identify components of the CIA triad
- Understand NIST frameworks

**My Notes:**

> **CIA Triad** — The foundational model for cybersecurity:
> - **Confidentiality**: Only authorized users can access specific assets or data
> - **Integrity**: Data is correct, authentic, and reliable
> - **Availability**: Data is accessible to those who are authorized to access it

**Security Frameworks:**

- **NIST Cybersecurity Framework (CSF)**: A voluntary framework with standards, guidelines, and best practices
  - 5 Core Functions: **Identify → Protect → Detect → Respond → Recover**

- **NIST Risk Management Framework (RMF)**: 7-step process
  1. Prepare
  2. Categorize
  3. Select
  4. Implement
  5. Assess
  6. Authorize
  7. Monitor

**Security Controls:**
- **Encryption** — Converting data from readable to encoded format
- **Authentication** — Verifying identity (MFA, biometrics)
- **Authorization** — Granting appropriate access levels

### Module 4: Cybersecurity Tools and Programming Languages

**Learning Objectives:**
- Identify common cybersecurity tools
- Understand the purpose of SIEM tools
- Recognize programming languages used in security

**My Notes:**

| Tool/Language | Purpose |
|---|---|
| **SIEM** (Splunk, Chronicle) | Collect and analyze log data for threats |
| **Network Protocol Analyzers** (Wireshark, tcpdump) | Capture and analyze network traffic |
| **IDS** (Suricata) | Detect and alert on intrusions |
| **Penetration Testing** (Metasploit) | Test security of systems |
| **Python** | Automate security tasks |
| **SQL** | Query databases for security investigations |
| **Linux CLI** | Manage systems, examine logs |

### Lab 2: Security Incident Analysis

**Objective:** Analyze a security incident using the NIST CSF framework.

- **Identify**: Asset inventory revealed unpatched web server
- **Protect**: Recommended firewall rule updates and patch management
- **Detect**: SIEM alert configuration for similar attack patterns
- **Respond**: Incident response plan activation and containment
- **Recover**: System restoration from backup and post-incident review

## Key Takeaways

1. The **CIA triad** (Confidentiality, Integrity, Availability) is the bedrock of all security decisions
2. The **NIST CSF** five core functions (Identify, Protect, Detect, Respond, Recover) provide a comprehensive security lifecycle
3. Historical attacks demonstrate that both **technical vulnerabilities** and **human factors** are exploited — defense requires addressing both
4. Entry-level analysts need proficiency in **SIEM tools, network analysis, scripting (Python), and Linux**
5. Security is an **evolving field** — continuous learning is essential
